Aegis Supply Chain Risk Detector

A web dashboard that helps spot risk in a software supply chain, so weak links show up in one place before they turn into a problem.

  • Next.js
  • TypeScript
  • Tailwind CSS
  • See code!

The idea

Weak links, in one place

Risk in a supply chain hides in the parts you depend on. This dashboard puts those parts on a map, scores each one, and lets you dig into any single node.

1. Map itSupply nodes are drawn on a tactical map, next to a list of threats.
2. Score itEach node gets a risk score, and you can open one up for a closer analysis.
3. Tune itPick an industry preset or edit the nodes yourself, and the dashboard follows.
