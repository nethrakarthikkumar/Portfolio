Aegis Forensic Analyzer

A Linux desktop app that scans a folder, hashes every file with SHA-256 and flags hidden, duplicate and suspicious files, then exports an audit report.

  • Java 21
  • JavaFX
  • SHA-256
  • MySQL
  • See code!

The idea

Proof of what is on a disk

Checking a folder by hand is slow and easy to get wrong. This app walks the files for you, gives each one a fingerprint and keeps a record you can hand over as an audit report.

1. ScanPick a folder and the app walks every file inside it.
2. FingerprintEach file gets a SHA-256 hash, so duplicates and changes stand out.
3. ReportFindings are stored, then exported as a CSV audit report.
